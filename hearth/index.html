Hearth OS

This is the kitchen for three adults in Erie County, NY. Shopper, cook sheet, budget split, and two rooms (House and Private).

This web page is only a sign on the door. The real kitchen program is not here. It cannot live on this public Netlify site — that would put private notes on the internet.

What you saw earlier

The phone opened a page that said “Discipline is the edge.” That is BEDROCK, a money app stored in the same GitHub box. It is not Hearth.

Where the real app is

On GitHub, the kitchen is the folder named hearth-os. It is a program for a computer in the house (PIN login, then the cook sheet and rooms).

Someone who can run a program on a computer should do this once:

cd hearth-os
cp .env.example .env
# change HOUSEHOLD_PIN and SECRET_KEY
python3 -m pip install -r requirements.txt
python3 -m uvicorn app.main:app --host 127.0.0.1 --port 8080

Then on that same computer, open http://127.0.0.1:8080. Default PIN is 4829. Change it.

Do not put Hearth on the open internet. Use the house Wi‑Fi or Tailscale.
