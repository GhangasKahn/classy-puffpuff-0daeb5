# SOVEREIGN SITEFORGE v3.0 — Cursor Agent Skill

Polymorphic, cinematic, award-grade website architecture for Cursor Agent / Composer.

## Install in Cursor

### Option A — Project skill (recommended)

1. In your project root, create:
   ```
   .cursor/skills/sovereign-siteforge/
   ```
2. Copy everything from this folder into that directory:
   ```
   SKILL.md
   references/
     core-protocol.md
     design-and-motion.md
     verification-and-handoff.md
   ```
3. Restart Cursor or reload the window.
4. Invoke with: `sovereign-siteforge skill` or describe an award-grade / brand-specific site build.

### Option B — Global user skill

Copy the same folder to:

```
~/.cursor/skills/sovereign-siteforge/
```

### Option C — Rules file (always-on for a project)

If you prefer a rules file instead of a skill, copy `CURSOR-RULES.md` contents into:

```
.cursor/rules/sovereign-siteforge.mdc
```

(or paste into your project Rules in Cursor Settings).

## What this skill enforces

- Truth before persuasion (no fake proof, urgency, or social)
- Concept before components (no default hero/feature-grid stamp)
- One governing idea per brand
- Signature interaction that is real and implemented
- Accessibility + performance as design requirements
- Full production build, not mood boards when a site was requested
