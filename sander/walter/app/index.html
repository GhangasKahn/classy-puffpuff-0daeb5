Build WALTER from the kernel out

Interactive breakdown of the shop-built drum thickness sander — explode the model, walk twelve assembly steps, check plywood and hardware, study the subsystems that actually failed on Walters' machine, and keep shop drafts on this device.

How to use this app

  1. Open Visualize — explode the sander and inspect groups
  2. Work Assembly drum → frame → table → conveyor → drive → tune
  3. Shop from Materials (Baltic birch, not MDF)
  4. Save grit / opening / electrician notes in Drafts
  5. Print or download CAD, sheets, and fab CSVs from Files

Progress

Checklist progress is stored in your browser (localStorage). Export JSON anytime from Drafts.
