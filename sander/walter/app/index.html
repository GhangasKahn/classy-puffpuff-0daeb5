0% assembled 3D Design

16″ closed frame · 5″ drum · 1089 RPM · Rev C · PLANFORGE

Build WALTER from the kernel out

Interactive breakdown of the shop-built drum thickness sander — explode the model, walk twenty-two LEGO assembly steps, check plywood and hardware, study the subsystems that actually failed on Walters' machine, and keep shop drafts on this device. Controlling drawings live in Planforge, not in this viz.

How to use this app

  1. Open Visualize — orbit the WebGL shop, then Play 22 steps
  2. Work Assembly drum → frame → table → conveyor → drive → tune
  3. Print the LEGO manual and read Planforge before cutting
  4. Shop from Materials (Baltic birch, not MDF)
  5. Save grit / opening / electrician notes in Drafts
  6. Print or download CAD, sheets, and fab CSVs from Files

Progress

Checklist progress is stored in your browser (localStorage). Export JSON anytime from Drafts.
