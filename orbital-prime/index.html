    Notes

    Look angles from geodetic observer and sub-satellite point on WGS-84. Topocentric east, north, up from ECEF. Azimuth via atan2(E, N). Elevation via atan2(U, √(E²+N²)). Range is the vector length.

    Passes run in the browser with satellite.js SGP4 against Celestrak GP. Thirty-second steps, 36 hours. Naked-eye needs elevation ≥ 10°, sun below −6°, and the station outside Earth’s shadow.

    Magnitude estimate: −1.8 + 5 log₁₀(range / 1000 km) + phase term.

    Pass score is a logistic prior on live features (elevation, estimated magnitude, cloud, precipitation, visibility, night/illumination, Kp). Coefficients are documented in js/score.js. It is not a trained black box and not a guarantee.

    Anyone can use this instrument. Location is a URL: ?lat=&lon=&sat=. No account. GPS is optional. Celestrak GROUP=stations is the catalog (ISS, Tiangong, and other stations — not Starlink).
