# ART DIRECTION FREEZE — Orbital Prime (OP-01)

Binding. Not a moodboard. Implement against this document.

Supersedes the olive-black night instrument and every neon HUD pass.

## 1. Governing concept

The instrument between you and the sky.

## 2. Emotional register

Industrial catalog. Hardware. Paper. Warehouse.

Teenage Engineering product sheet × Virgil Abloh / Off-White quotation graphics × brutalist print.

## 3. Anti-references

- Dark SaaS dashboards, cyan/purple “LIVE” pills, glass headers
- Cyberpunk HUD, scanlines, glitch, OLED chrome, mil-spec “MISSION CLUSTER”
- WebGL black holes, particle fields, nebula posters, 3D Earth
- Emoji docks, sci-fi display fonts (Syne, Chakra Petch), glow, blur
- Anything that reads as “tech product” or “space app”

## 4. Color tokens

| Token | Hex | Usage |
|---|---|---|
| `--paper` | `#F2EDE4` | Page ground. Cream plastic / catalog stock. |
| `--paper-2` | `#E8E2D6` | Recessed wells (plot, radar, gauges). |
| `--ink` | `#111111` | Type, rules, ticks. |
| `--mute` | `#6B6458` | Captions. AA on paper. |
| `--orange` | `#FF5A00` | TE signal. Active ticks, lock pip, module numbers, one product disc. |
| `--yellow` | `#FFE600` | Off-White industrial yellow. Hover, pass highlight, toast. |
| `--ok` | `#1A7A3A` | Gate PERFECT. |
| `--warn` | `#C45A00` | Gate MARGINAL. |
| `--bad` | `#B01010` | Gate OBSTRUCTED. |

No cyan. No glow. No radius. No glass.

## 5. Type

- Display: Archivo Black / Impact. Uppercase nameplate and module titles.
- Body: Inter / Helvetica. Industrial captions, sentence case notes.
- Data: Space Mono. Numerals, T-minus, tables.

Hero wordmark is huge. FACE is a spoken command in display size that still wraps at 390. Module numbers (`01`–`12`) are mono orange.

Quotation marks are graphics. Strikethrough is a graphic (`software` struck, hardware remains). `™` is allowed on the SKU.

## 6. Geometry

- Radius: 0.
- Rules: 2–4px black, not hairline glow.
- Numbered modules, Swiss / catalog grid.
- Sticky dock: `01 LOCK / 02 PASS / 03 NOTES / 04 FINDER` — digits, not emoji.
- SKU mast: `OP-01`. Depth 1–4 as hardware keys.
- One rotating orange disc (TE knob). No shader behind the page.

**390px:** no horizontal scroll. FACE readable. T-minus wraps. Dock four equal columns.

## 7. What “done” looks like

- Cream paper, black ink, orange signal, yellow hazard. Immediately TE / Off-White, not NASA, not HUD.
- Live ISS lock, FACE, gauges, sky plot, weather gate, SGP4 table still work.
- No WebGL background. No scanlines. No cyan.
