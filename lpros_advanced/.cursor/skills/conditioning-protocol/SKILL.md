# Conditioning Protocol Skill

## When to use

- Installing reliable procedures (verification, listings checks, triad forecasts)
- Extinguishing undesired agent behaviors (hallucinated numbers, skipped audits)
- Designing onboarding or coach loops with measurable adherence
- Pairing cues with correct responses under an authoritative curriculum

## Dual modes

### Authoritative conditioning

- Clear rules, explicit criteria, immediate correction.
- Use for safety, capital, and non-negotiable LPROS constraints.
- Authority names the standard; compliance is binary and logged.

### Pavlovian (associative) shaping

- Pair a **cue** with a **correct response** and a **reinforcer**.
- Shape complex skills in successive approximations.
- Use for fluency (habits) once authoritative standards exist.

## Procedure

### 1. Target behavior

- Write an observable behavioral definition (not a vibe).
- Example: “Before any price claim on an alt asset, attach listing URL or mark listings-needed.”

### 2. Cue design

- External cue: checklist item, tool gate, UI prompt, Brain contract field.
- Internal cue: situation pattern (“about to output a number”).
- Make the cue impossible to miss at the decision point.

### 3. Reinforcement schedule

| Phase | Schedule | Purpose |
|-------|----------|---------|
| Acquisition | Continuous reinforcement | Establish link |
| Stabilization | Fixed ratio / interval | Maintain |
| Maintenance | Variable / intermittent | Resistance to extinction |

- Reinforcers: success flags, unlocked next step, reduced friction, explicit praise in logs — never capital-risking shortcuts.
- Punishment/correction: immediate, specific, paired with the correct alternative.

### 4. Measurement

- Track response rate to cue, latency, error type, relapse rate.
- Pre-define mastery threshold (e.g., 95% cue compliance over N trials).
- Run `accuracy-audit` and `behavior-analysis` on the conditioning program itself.

### 5. Output contract

```text
CONDITIONING PLAN
- Target behavior (observable):
- Mode: authoritative | Pavlovian | mixed
- Cue → correct response → reinforcer:
- Correction for errors:
- Schedule by phase:
- Mastery metric + threshold:
- Extinction / relapse plan:
```

## Anti-patterns

- Vague goals (“be more rigorous”) without observable behavior
- Reinforcing speed over correctness in capital contexts
- Removing cues before mastery (premature autonomy)
- Shame-based punishment without a replacement response
