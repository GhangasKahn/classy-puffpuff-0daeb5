Clock A/B (paper on)

  1. Disconnect power — Unplug. Hood off. Paper off for TIR; paper on for A/B parallel.
  2. Seat the table in the ways — Raise/lower through full travel. No bind, no rock. Winding sticks on wear face — no twist.
  3. Drum TIR — Indicator on mid-span OD. Rotate by hand. If > 0.002″, re-true on P-013 before wrapping.
  4. Wrap & re-clock — Velcro then spiral paper. Paper is not uniform — A/B will change. This is the measurement that matters.
  5. A/B parallel — Same indicator height, drive then idler. Uncouple left Acme; 1/10 turn ≈ 0.1000″. Recouple. Set home dog.
  6. Hold-down height — Feelers under each roller vs drum. 0.030″ below. Leading snipe → ease outfeed spring; trailing → ease infeed.
  7. Witness board — 6″ × 16″ maple, 80 grit, one pass. Ridge at overlap = idler high/low. Caliper corners. Log in the Build app.
  8. Taper mode (optional) — Uncouple left, drop idler a few thousandths, sand, then return to home dog — do not re-invent parallel each time.

Assembly

  1. A1 Template & stack-drill sides — Clamp P-001L/R face-to-face. Drill bearing CL at Y 11″ / Z 18.5″, Acme holes, indicator pad as one stack (S-008).
  2. A2 Dados, way rebates, box + UHMW — Split the pair. Dado J-001 (0.25″) and rebate J-002 (0.520″) on inner faces only. Glue P-003, square diagonals, bond P-007.
  3. A3 Pack-bore discs & laminate drum — Bandsaw P-008/P-009 oversize. Stack in P-015; ream ⌀¾″ as a pack (J-005). Key, 1 mm MDF relief, static-balance P-009.
  4. A4 Fixed drive bearing, floating idler — H-001 locked on P-001L (J-006). H-002 on axial-float slots on P-001R (J-007).
  5. A5 Motor cradle, coplanar pulleys, lock — Straightedge across H-003/H-004. Gravity tension, lock P-012 (J-008).
  6. A6 Torsion-box table + wear face — P-004 + P-005 @ 4″ o.c., glue. Flatten. Bond P-006. Diagonals ≤ 0.004″.
  7. A7 Dual Acme lift + chain couple — P-016 + H-007. H-008 chain. Left clutch + home dog. Table must rise in the ways without twist.
  8. A8 Hold-down roller yokes — P-014 + H-009. Set 0.030″ below drum OD, paper on. Too much spring = snipe.
  9. A9 Kerf-bend dust hood — P-011 kerf, wet, glue, fill. H-019 4″ port. Clear oscillator stroke if fitted.
  10. A10 True drum on full-width sled — P-013 abrasive face-up on the ways. TIR ≤ 0.002″. Then H-022 Velcro + spiral paper.
  11. A11 Indicator clock A/B — parallel home — Paper on. |A−B| ≤ 0.003″. Lock home dog. Record the reading.
  12. A12 Test panel + pass schedule — 80 / 120 / 180. Caliper four corners. If scatter > 0.003″, re-clock. Finish at 0.001″.
