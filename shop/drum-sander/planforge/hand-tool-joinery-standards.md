# Hand-Tool Joinery Standards

## Core Principle
When a package specifies hand-tool execution (or when the user works primarily with hand tools), every joint sheet must provide a cutting sequence that a skilled hand-tool worker can follow without ambiguity. Prefer methods that create clean knife walls, controlled paring, and progressive accuracy rather than relying on power-tool equivalents.

## Layout & Marking
- Establish one true face (Face A) and one true edge (Edge B) first.
- Use a sharp marking knife for all shoulders and critical lines. Pencil is secondary.
- Marking gauges and cutting gauges are preferred for parallel lines; set once and transfer consistently.
- For Japanese-influenced work, integrate centerline layout with hand-tool marking methods.

## Preferred Hand-Tool Sequence for Drawbored Mortise-and-Tenon
1. Establish Face A and Edge B on both post and rail.
2. Layout from the chosen datum (face or centerline).
3. Knife the tenon shoulders all around.
4. Cut tenon cheeks (rip or split + plane/pare to the line).
5. Cut the mortise (bore waste then chop, or full chop with successive chisel sizes). Provide drain relief on exterior joints.
6. Dry fit. Check shoulder contact under raking light. Local gap ≤ 1/32".
7. Bore the peg hole in the post.
8. Transfer the hole to the tenon with the specified drawbore offset.
9. Test with a sacrificial peg. Drive the final riven peg only after acceptance.

## Chisel & Saw Discipline
- Use the largest appropriate chisel that still fits the work for efficiency and flatness.
- Pare to the knife line rather than trying to saw exactly to the line on critical shoulders.
- Japanese pull saws and Western backsaws both have roles; specify the preferred action when it affects the sequence.
- Keep chisels razor sharp. Dull tools destroy precision and increase physical strain.

## Solo & Low-Strain Considerations
- Work at a comfortable height on stable trestles or a low workbench.
- Use holdfasts, clamps, or simple jigs so both hands remain free for the tool.
- Avoid sequences that require supporting heavy stock while cutting critical joints.
- Module sizes should allow one person to handle and position pieces safely.

## Integration with User Tooling
When the user has documented high-precision hand tools (e.g., fine chisels, precision planes, dovetail or tenon guides, high-quality saws, Incra-style measuring systems), reference them in the sequence where they provide clear advantage. Do not assume the presence of any specific tool unless it has been established in the project context.

## Acceptance Criteria (Hand-Tool Specific)
- Shoulders bear continuously; local gap ≤ 1/32" under raking light.
- Tenon seats by hand or light mallet taps only.
- No crushed fibers, split ends, or diagonal grain at the peg location.
- Peg driven cleanly; proud end trimmed, chamfered, and sealed.

## 3D-Print + Hand-Tool Workflow
Complex or high-value joints should still be prototyped in 3D print at 1:1 before committing the final wood, even when the final execution is entirely by hand. The print verifies geometry; the hand tools execute the refined version.
