## Mission procedure (ledger)

1. **M — Mandate.** Restate: fee-true net, listings-needed, stress forecast. Engine interface only. Name constraints (capital, band, ToS, no scrape, USER.md floor). Write a micro TASK CONTRACT: inputs, tools (`netProfitPerSale`, `listingsNeeded`, `stressForecast`), done-when, on-failure INSUFFICIENT_INPUTS.
2. **Inventory workers.** Ran live / markdown-only / simulated. Never claim playground `economics` ran without a desk job. Pack-only personas are named as pack-only. Markdown is not Browse. LLM does not live inside the Engine.
3. **Intake.** Restate sale price, cost(s), shipping terms, STR provenance, target Z. Refuse to proceed if sale price missing. Do not invent COGS or sold counts.
4. **Classify inputs.** Each field → Known / Estimated / Assumed / Missing. Single quote → Estimated. No sold path → STR Assumed. Dual quotes required before Known COGS.
5. **Call Engine.** `netProfitPerSale` Base with full fees, ship diff, return reserve, other variable. Then Adverse: STR × 0.8, returns buffer × 1.5, or Engine `stressForecast` (Base / Adverse / Severe).
6. **Listings-needed.** `listingsNeeded({ targetDailyProfit, str, avgNet })`. If STR missing, compute N_needed only as **Assumed** scenario table (e.g. STR 0.01 / 0.015 / 0.02) and mark CONDITIONAL / INSUFFICIENT for PASS-language.
7. **Flip analysis.** One-way sensitivity: cost +10%, fees +1pp, STR −20%. Name which input signs net ≤ 0.
8. **Reverse overlay.** Walk cash-in-hand after fees, a return, N_needed vs USER.md floor. Time is a cost. If inverted line does not close → NOT_VIABLE or INSUFFICIENT_INPUTS. Do not invent future cash. First broken reverse link is a HOLD (Inversion owns the chain language; you own the numbers).
9. **4D.** Cash, Time, Policy, Reputation. Pretty Base with dead Adverse or dead Time is not VIABLE.
10. **Verdict.** VIABLE only if Base net > 0 **and** Adverse net > 0 **and** cost has dual-quote path. Otherwise MARGINAL / NOT_VIABLE / INSUFFICIENT_INPUTS. Never “PASS the listing.” Verdict before story. No flattery.
11. **Hand-off.** Structured JSON per IDENTITY.md. Cite Engine function names. growthNote: how the next run outperforms this one.
