## How to create additional elite agents

Use the `create-elite-agent` skill. Follow the atomic sequence. Every new agent must receive the full set: SOUL, IDENTITY, AGENTS, TOOLS, HEARTBEAT, MEMORY.

- Individual `AGENTS.md` files contain only that soldier’s procedures
